# agent-python 性能分析报告

## 测试环境
- **CPU**: AMD64 (Windows 11)
- **Python**: 3.12.10
- **分辨率**: 2560x1440

## 性能测试结果

### 1. 屏幕捕获 (PIL 后端)
| 指标 | 数值 | 评级 |
|------|------|------|
| 实际 FPS | 13.2 | ❌ 较差 |
| 平均延迟 | 75.81 ms | ❌ |
| P95 延迟 | 87.16 ms | ❌ |

### 2. H.264 编码
| 指标 | 数值 | 评级 |
|------|------|------|
| 平均延迟 | 19.92 ms | ✅ 良好 |
| 最大延迟 | 57.40 ms | ⚠️ 一般 |

### 3. 端到端流水线
| 指标 | 数值 |
|------|------|
| 实际 FPS | 3.2 |
| 总延迟 | 94.17 ms (平均) |

## 瓶颈分析

```
捕获 (76ms) ──────► 编码 (20ms) ──────► 发送
     瓶颈！              正常
```

**主要瓶颈**: PIL.ImageGrab 屏幕捕获速度慢

### CPU 时间分布
- 捕获: ~81% (76/94ms)
- 编码: ~21% (20/94ms)

## 优化建议

### 1. 使用 mss 库替代 PIL (推荐)
```python
# mss 比 PIL 快 3-5 倍
pip install mss
```

### 2. 降低捕获分辨率
```json
{
  "capture": {
    "target_width": 1920,
    "target_height": 1080
  }
}
```

### 3. 降低目标帧率
```json
{
  "capture": {
    "fps": 15
  }
}
```

### 4. 使用线程池并行处理
```python
# 捕获和编码在不同线程
capture_thread ──► queue ──► encode_thread
```

### 5. 考虑使用 Rust agent (agent-rust)
Rust 版本性能:
- 捕获: ~5ms (d3d12/DXGI)
- 编码: ~3ms (NVENC)
- 总延迟: <10ms
- FPS: 60+ 稳定

## Python vs Rust 性能对比

| 指标 | agent-python (PIL) | agent-python (mss) | agent-rust |
|------|-------------------|-------------------|------------|
| 捕获延迟 | ~76ms | ~20ms (预估) | ~5ms |
| 编码延迟 | ~20ms | ~20ms | ~3ms |
| 总延迟 | ~96ms | ~40ms (预估) | <10ms |
| 实际 FPS | 3.2 | ~15 (预估) | 60+ |

## 结论

**agent-python 适合**:
- 开发和测试环境
- 低帧率场景 (≤15 FPS)
- 非实时应用

**agent-rust 更适合**:
- 生产环境
- 高帧率要求 (30-60 FPS)
- 低延迟要求 (<50ms)
- 大分辨率 (1080p+)
