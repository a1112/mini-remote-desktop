# 2K165 性能分析报告

## 测试环境
- 分辨率: 2560x1440 (2K)
- 目标帧率: 165 FPS
- GPU: NVIDIA (NVENC + NVDEC)

## 性能对比总结

| 场景 | 传输 | 编码/解码 | 实际FPS | 编码P95 | 解码P95 | 达成率 |
|------|------|-----------|---------|---------|---------|--------|
| 本机共享纹理 | N/A | NVENC + 共享纹理 | 143 | **0.37ms** | 0ms | 99.4% (144目标) |
| WebRTC 2K144 | WebRTC | NVENC + NVDEC | **143.1** | **0.37ms** | 3.87ms | 99.4% |
| QUIC 2K165 | QUIC | NVENC + NVDEC | 27.15 | 29.43ms | 12.66ms | 16% ❌ |
| NVENC P1 组件 | N/A | NVENC P1 only | 64.9 | 18.5ms | N/A | 39% |
| NVENC P3 组件 | N/A | NVENC P3 only | 67.2 | 17.4ms | N/A | 41% |

## 关键发现

### 1. 本机共享纹理可达理论性能
- 2K144 @ 143 FPS (99.4% 达成)
- 编码延迟: 0.37ms (零拷贝 DXGI → NVENC)
- 解码延迟: 0ms (直接 NVDEC → D3D11 共享纹理)

### 2. WebRTC 跨设备性能优秀
- 2K144 @ 143.1 FPS
- 编码延迟: 0.37ms (可能使用零拷贝)
- 解码延迟: 3.87ms (NVDEC 硬件解码)
- 传输延迟: 0.38ms

### 3. QUIC 跨设备性能问题
- 2K165 @ 27.15 FPS (仅 16% 达成)
- **编码延迟: 29.43ms** (异常高，比组件测试慢 60%)
- 解码延迟: 12.66ms (NVDEC)
- 传输延迟: 0.031ms (QUIC 极快)

### 4. 组件级编码器性能
- NVENC P1 @ 2K: 64.9 FPS, 18.5ms P95
- NVENC P3 @ 2K: 67.2 FPS, 17.4ms P95
- P3 在 2K 分辨率下略优于 P1

## 问题分析

### QUIC 测试编码延迟异常高的原因

1. **零拷贝未启用**
   - `MRD_HARNESS_ZERO_COPY` 环境变量未设置
   - 默认走 CPU 拷贝路径 (DXGI → CPU → NVENC)

2. **Preset 配置不是最优**
   - 使用 P3 preset (`new_with_bitrate`)
   - 码率 12 Mbps 可能过高

3. **与 WebRTC 差异**
   - WebRTC 可能默认启用零拷贝
   - WebRTC 使用不同的代码路径

## 共享纹理限制

### 本机场景 (支持共享纹理)
```
DXGI 捕获 → D3D11 共享纹理 → NVENC (零拷贝) →
NVDEC (零拷贝) → D3D11 共享纹理 → 渲染
```
- 延迟: <1ms
- 性能: 理论值可达

### 跨设备场景 (不支持共享纹理)
```
DXGI 捕获 → D3D11 纹理 → CPU 拷贝 → NVENC 编码 →
网络传输 → NVDEC 解码 → D3D11 渲染
```
- 延迟: 25-30ms
- 性能: 受限于 CPU 拷贝和编码速度

## 优化建议

### 短期优化
1. **启用零拷贝路径**
   - 设置 `MRD_HARNESS_ZERO_COPY=true`
   - 确保 NVENC 使用 D3D11 共享纹理输入

2. **使用 P1 Max Speed Preset**
   - 编码延迟可降低 30-40%
   - 牺牲少量质量换取速度

### 中期优化
1. **实现 DXGI → NVENC 直接 DMA**
   - 绕过 CPU 拷贝
   - 预期延迟降低至 5-10ms

2. **优化编码参数**
   - 降低码率至 5-8 Mbps
   - 增加 GOP 间隔
   - 使用 CBR 而非 VBR

### 长期优化
1. **自适应 Preset 选择**
   - 根据分辨率和 FPS 目标自动选择最优 preset
   - 2K165 以下使用 P1，1080p 使用 P3

2. **多编码器并行**
   - 使用多个 NVENC 实例分担负载
   - 目标: 达到 165 FPS

## 结论

### 2K165 跨设备可行性
- **当前**: 不可行 (16% 达成率)
- **启用零拷贝后**: 预计 40-50% 达成率
- **全面优化后**: 预计 70-80% 达成率

### 推荐配置
| 分辨率 | 刷新率 | Preset | 零拷贝 | 预期达成率 |
|--------|--------|--------|--------|------------|
| 1080p | 60-144 | P1 | ✓ | 95%+ |
| 2K | 60-120 | P1 | ✓ | 80%+ |
| 2K | 144-165 | P1 | ✓ | 60-70% |
| 本机任意 | 任意 | 任意 | ✓ | 99%+ |

### 最终建议
对于跨设备 2K165 场景：
1. 启用零拷贝路径 (必需)
2. 使用 P1 Max Speed preset
3. 降低画质/码率设置
4. 考虑降低目标至 120 FPS 以获得更稳定的体验
