# Junk Area

`junk/` stores material that is not part of the active product mainline.

Contents may include:

- historical implementations
- deprecated controllers and agents
- temporary benchmarking scripts
- captured media outputs
- one-off experiment files
- recovered reference trees

Rules:

- Do not add new product code here.
- Do not treat paths here as architecture-defining.
- Move files out only when they are intentionally re-implemented into `apps/`, `crates/`, or `labs/`.
