## 2. 硬件编码可用性

### PyAV 中可用的 H.264 编码器
```
✅ h264_nvenc      - NVIDIA GPU 硬件编码
✅ h264_mf         - Windows Media Foundation
✅ libx264         - x264 软件编码
✅ libopenh264     - Cisco 开源 H.264
✅ h264            - 通用 H.264 编码器
```

### 编码器性能对比 (1920x1080)

```
┌───────────────┬─────────┬──────────────┬────────────┐
│ 编码器        │  FPS    │  帧大小      │  类型      │
├───────────────┼─────────┼──────────────┼────────────┤
│ h264          │  72.5 ⭐│  159 KB      │  通用      │
│ libopenh264   │  60.9   │  111 KB      │  软件      │
│ libx264       │  52.4   │  159 KB      │  软件      │
│ h264_mf       │  45.8   │  151 KB      │  Media Fnd │
│ h264_nvenc    │  37.3   │  78 KB       │  NVIDIA    │
└───────────────┴─────────┴──────────────┴────────────┘
```

### 分析与建议

1. **NVENC 为何不是最快?**
   - 容器编码方式有额外开销
   - 单帧测试中 GPU 传输开销超过编码收益
   - NVENC 在批量编码和更高分辨率下才体现优势

2. **何时使用硬件编码?**
   - ✅ 高分辨率 (1440p, 4K)
   - ✅ 多路并发编码
   - ✅ 长时间编码场景
   - ❌ 单帧低延迟编码 (软件更快)

3. **推荐配置**

对于 30-60 FPS 远程桌面场景:
```python
# 方案 1: 软件编码 (当前推荐)
stream.codec_context.options = {
    'preset': 'ultrafast',      # 最快编码速度
    'tune': 'zerolatency',      # 零延迟调优
}

# 方案 2: 硬件编码 (高分辨率场景)
stream.codec_context.name = 'h264_nvenc'
stream.codec_context.options = {
    'preset': 'fast',
    'tune': 'll',               # low latency
    'rc': 'cbr',                # 恒定比特率
}
```

## 3. 端到端性能估算

### 1080p @ 30 FPS 配置
```
┌─────────────────┬──────────┬──────────┐
│ 阶段            │  耗时    │  累计    │
├─────────────────┼──────────┼──────────┤
│ GDI 捕获        │  16 ms   │  16 ms   │
│ RGB → BGRA 转换 │  2 ms    │  18 ms   │
│ H.264 编码      │  19 ms   │  37 ms   │
│ 网络传输        │  10 ms   │  47 ms   │
│ 解码显示        │  5 ms    │  52 ms   │
├─────────────────┼──────────┼──────────┤
│ 总延迟 (预计)   │          │  ~50 ms  │
└─────────────────┴──────────┴──────────┘
```

### 性能优化建议

1. **配置优化**
   - 使用 1080p 而非 1440p
   - libx264 preset=ultrafast
   - 降低比特率至 3000-5000 kbps

2. **架构优化**
   - 捕获线程与编码线程分离
   - 使用帧队列缓冲
   - 零拷贝内存视图

3. **硬件加速**
   - 当前软件编码已足够快
   - NVENC 需要更多调优才能发挥优势

### GDI 性能开销
- ⭐ **CPU**: 每核仅 3.2%，非常高效
