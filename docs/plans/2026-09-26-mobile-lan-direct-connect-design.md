# 移动端局域网直接连接设计

用户要求在局域网内发现设备后无需输入密钥，点选即可连接。

## 方案

移动网关的桌面控制、手机画面发布和手机控制 WebSocket 只接受回环或私有地址来源。请求 `Host` 必须是私有地址或 localhost；浏览器请求还须满足 `Origin` 与 `Host` 一致，防止其他网页及域名重绑定借浏览器连接本机网关。手机控制页面禁止被其他页面嵌入。Android 原生 WebSocket 不发送 `Origin`。网关在 WebSocket 建立后发送 `ready`，不再等待密钥报文。

Android 启动时即探测当前及常见家用网段，扫描结果点选后立即开始电脑连接。手机作为被控端时，仍须在应用中主动启动共享，并批准 Android MediaProjection；辅助功能仍需在系统设置中手动开启。电脑浏览器页面打开后自动建立手机控制连接。

此设计把可路由私有网络视作可信网络。同网段或经路由可达网关的其他设备可以控制电脑；手机只有在用户启动共享后才会被控制。网关默认监听回环地址，开放到 LAN 必须显式设置绑定地址并配置专用网络防火墙。

## 验证

验证私有地址允许、公网地址拒绝、恶意浏览器 Origin 拒绝；验证无密钥 WebSocket 的桌面画面和手机画面/控制链路；构建 Android APK 并安装到小米 14 Pro，确认扫描结果可点选连接。
